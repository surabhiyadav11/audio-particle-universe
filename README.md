# 🎵 Audio Particle Universe

> **A simple and dynamic audio visualizer where sound brings particles to life.**

---

## ✨ Key Features

* 🎶 **Sound-Reactive Particles:** Particles move and react to audio frequencies and beats.
* ⚡ **Fast & Smooth:** Built with **React** and **Vite** for smooth animations.
* 🎨 **Canvas Graphics:** Uses **HTML5 Canvas** for particle physics and visual effects.
* 🎛️ **Audio Engine:** Uses the native **Web Audio API** for real-time audio processing.
* 🖱️ **Interactive Experience:** Visuals respond dynamically while audio is playing.

---

## 🛠️ Tech Stack

* ⚛️ **Framework:** React
* ⚡ **Build Tool:** Vite
* 🎨 **Graphics:** HTML5 Canvas / CSS3
* 🔊 **Audio Processing:** Web Audio API
* 💻 **Language:** JavaScript

---

## 🚀 Quick Start

Follow these steps to run the project locally:

```bash
# 1. Clone the repository
git clone https://github.com/surabhiyadav11/audio-particle-universe.git

# 2. Go into the project directory
cd audio-particle-universe

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The project will then be available on the local development server provided by Vite.

---

## 📌 Project Purpose

Audio Particle Universe demonstrates how **audio data can be converted into real-time visual effects** using JavaScript, Canvas, and the Web Audio API.

It combines audio processing with particle animation to create an interactive and visually engaging experience.
